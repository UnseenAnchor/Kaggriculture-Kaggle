## 核心结论：为什么我们在 ~1990~2000 卡住

1. **榜跟随 active submission 的实时 Elo**，每次提交重置重爬 → 频繁换提交是自伤（V52 误提 + V53 回滚已付两次重爬代价）。
2. **V50 (8/4) 是状态机天花板**：28 代迭代竞品（V47/48/49/51/52/53）全部死于「执行层耦合」——任何换路线/动物配比/裸 tape 替换 V50 的核心路线都会崩（Hamburger 0W-8L, bank 26k）。
3. **执行层不可移植（普适）**：V50 的执行层只对 8/4 主线有效；套到 6/12、8/6 tape 全部崩盘。
4. **镜像墙**：线上主流对手分两族——8/6（被 V50 碾压 5W-0L）和 8/4 同构（V50 vs 同类 6W-5L，**纯 seed 噪声**，双方动作轨迹完全一致，胜负由随机地图决定）。
5. **无失败族可复现**：V50 对 8/4 的败局是 seed 决定，非策略缺陷 → 无因果突破口。

## 可优化方向（按证据强度排序）

### A. 镜像同构对抗（8/4 内突破）— 唯一有直接提升空间的点
- **现状**：V50 打同构 8/4 是 50/50 抛硬币，因为双方执行相同动作序列。
- **机理**：胜负由 seed 地形（weed 簇位置、作物蔓延）决定 → 谁是「先手优化」或「seed 感知」谁赢。
- **可挖**：对 6W/5L 的 11 个镜像局做因果分析——哪些 seed 特征（weed 距产线距离、开花时点）导致输。若能训练 V50 在这些地形上快一步（保留 stateful 主线的**确定性动作微调**，非盲调 alpha），可把镜像局从 50% 拉到 60-70% → 分数 +100~200。
- **约束**：必须保留 8/4 主线 + 执行层；只加「在某 seed 特征下优先级重排」。这是唯一不改执行层耦合、有可测画像的方向。

### B. 识别并应对新的 stateful 对手族
- meta 是**灰度环境**，8/6 目前被 V50 碾压，但若 8/6 对手升级为 stateful（非 tape），情况会变。
- **可挖**：持续监控 V53 新踝，新出现的高分对手若配比非 8/4/8/6，提取其 stateful 行为做针对性事前预判。

### C. 彻底换引擎（高投入，低概率）
- 用完全不同的 stateful 架构（RL / MCTS 短视野 / 需求预判网络）。
- **否决理由**：28 代尝试已证明执行层耦合是死结；没有足够算力做 RL 训练；风险极高，几乎必然重蹈 V47-53 覆辙。

### D. 防守：保持 V53 active 不再动
- 当前 1926.8-1992，TOP500 门槛 ~2239，差 ~300+。
- 不动 = 至少停在 908/5165。动 = 重爬风险。
- 只有当新候选**有因果证据**且能通过完整本地闸门才提交。这是纪律底线。

## 建议
**优先方向 A**：做镜像 seed 因果分析。这是唯一「不违反失败教训」「有可测量画像」「不改执行层耦合」的突破口。分析产出物 = 一份「seed 特征 → 决策微调」表，先本地跑 8/4 镜像 100 seeds 验证胜率提升，通过闸门再考虑提交。

## 方向 A 收尾结论（2026-08-18，已穷尽）

方向 A 被系统性穷尽，结论为**不可行**，因果链如下：

1. **11 个线上 8/4 对局里 ~10 个是 V50 严格克隆**（开局逐字节一致）：我们在与自己打。胜败（-318 ~ -3688）由 seed 撮合噪声决定，**无学习空间**。克隆镜像局中双方动作多维集几乎全等，仅有 5-10 个 SELL 的数量微差。
2. **唯一真异种 = Bruce (94198691, -3010)**：2cow+2sheep 起手 → 滚到 **10cow/4sheep = 14 animals**。它与 8/6(14)、17羊(17) 同属「≥13 animal 高产能主线」——正是 V50 所有大败的家。
3. **V50 固定 8cow/4sheep=12 animals，产能结构性不足**。这是镜像墙 + 产能不足的双重根因。
4. **无法用本地 tape 建立 seed 控制的镜像对照**：线上 8/4 对手是 stateful，裸 tape 在新 seed 上不能适应 weed → 本地全胜是低估（V53 已验证该陷阱）。
5. **复刻 14-animal = 触执行层耦合死结**：V47/48/49/51/52/53 已普适证伪「任何改变 V50 核心动物/配比的 stateful 替换都崩」。

**收尾决定**：方向 A 关闭。V50 (12 animals) 在自身架构下已是上限 1992。无候选可提交。保持 V53 active 不动。

## 新方向（方向 F）

V50 的 12-animal 产能不足是唯一被证实为真、且与对手无关的根因。所有「在 V50 执行层框架内换配比」都死于耦合。因此新方向 = **在不动 V50 执行层内部结构的前提下，验证是否存在一条能承载 14-animal 产能、又不依赖 V50 执行层的独立 stateful 架构**。但在任何编码前，必须先有因果证据证明该架构能存活——否则重蹈 28 代失败（不计入候选编码）。

## 方向 F 收尾（2026-08-19，已穷尽，verdict=关闭）

方向 F 做了完整因果验证（修复 step 对齐 bug + 逐层剥离执行层 + 全部组合头对头）：

1. **发现一个 bug**：旧「执行层不可移植 / 6·12+exec 崩 26k」读数源自 step 对齐错误（extract_trace_agent 用 obs.step+1，内嵌主线用 obs.step）。修复后 6/12 完整主线恢复 bank 175k（而非 26k）。
2. **执行层对 6/12 几乎无损也无益**：裸 6/12 175,070 → +exec 174,919。提升全来自 step 修正。
3. **决定性头对头 vs V50**：
   - 6/12+weed（V55）：2W-2L（复现 V52 结局）
   - 6/12 裸（V52-true）：2W-2L（weed 层无贡献，两 seed 无干扰）
   - 8/6+exec（V54）：0W-4L（本地弱）
4. **线上 8/6 主导但本地 tape 弱**（0W-4L）→ 证明线上优势是 stateful 行为，无 tape 能复现。
5. **结论**：无任何 14-animal tape（裸或 +V50 执行层）能本地击败 V50（最佳 2W-2L 抛硬币）。方向 F 关闭。V53 (V50) 保持为最强 artifact，不提交。
